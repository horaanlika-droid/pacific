# ПАСИФИК КИТ · PK-900

Мобильная барная станция из нержавеющей стали AISI 304 для выездных мероприятий.
Ровно 8 элементов, собирается без инструмента за 5–7 минут вдвоём, в разобранном виде
укладывается в плоский чехол-сумку.

- Габариты в сборе: **900 × 600 × 1050 мм** (борт выдачи 1050 мм, рабочая часть 850 мм — на высоте бедра)
- Габариты чехла: **1180 × 720 × 145 мм**
- Масса: металл 28,8 кг, комплект с чехлом ≈ 34 кг

## Что в репозитории

```
cad/pk_geom.py    параметрическая геометрия деталей (мм, K-фактор 0,33)
cad/pk_dxf.py     экспорт DXF: CUT / BEND / INFO / SHEET + раскладка листов
cad/pk_draw.py    чертёжные примитивы и изометрия (reportlab)
cad/pk_album.py   14-листовой альбом A3
docs/             ПАСИФИК_КИТ_альбом.pdf — проект целиком
dxf/              12 DXF на лазер + INDEX.txt
```

## Сборка

```bash
cd cad
python3 pk_geom.py     # проверка массогабаритов
python3 pk_dxf.py      # dxf/*.dxf + раскладка + INDEX.txt
python3 pk_album.py    # docs/ПАСИФИК_КИТ_альбом.pdf
```

Зависимости: `reportlab`, `ezdxf` (Python 3.11).

## Ключевые решения

- Фасад — три блока 900 × 334 с зазорами 3 мм, лицо 1008 мм; блоки заменяются отдельно.
- Соединения без резьбы в лицевых плоскостях: крючок-язычок 20 × 11 в паз-«скважину»
  Ø13 + 9 × 26 (шаг 154), шипы 20 × 6 блок-блок, кулачковые замки F1 + штифты Ø9.
- Зона выдачи — съёмный лоток с перфорацией 40 × 3 (90 шт.), уклон дна 1,5°, дренаж
  в канистру 3 л. Борт лотка — верхняя плоскость бара 1050, по фронту 140 мм.
- Рабочая поверхность (столешница E7) опущена до **850 мм** (−200 мм от борта выдачи 1050 мм, на высоту бедра бармена) для удобной работы с шейкером, мойкой и льдом; боковые стенки выполнены ступенчатыми (1020 / 820 мм).
- Рабочая зона: слева раковина убрана — по фронту 4 отсека 90 × 160 R8 (шаг 108 мм) под небольшие гастроёмкости GN 1/9 и за ними сплошная рабочая площадка 245 мм; справа раковина поделена пополам перемычкой 20 мм на две секции 150 × 290 R12 (X 480…630 и 650…800); смеситель Ø35 по оси перегородки, ринсер Ø60, кабельный ввод Ø50.
