# PK-POP-900 · файлы для ЧПУ

Фанера берёзовая 12 мм, листы 1220 × 2440 мм. Единицы — мм, DXF R2010.

- `PK-POP-01 … 07` — отдельные детали (по одной на файл; количество — в концепции).
- `PK-POP-07` — выдача: плита 900 × 140 со слотами и логотипом (сквозной рез).
- `PK-POP-NEST_sheet1/2.dxf` — раскрой на листы.
- Слои: `CUT` — рез, `DRILL` — Ø4 под винты, `TEXT` — подписи (не резать).
- Вставка мойки — покупная, не в DXF.
- Механизм складывания не нанесён: ждём выбор варианта A или B.
- Генератор: `cad/pk_popup.py`.
